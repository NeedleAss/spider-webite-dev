# CareRover V6 presentation

此目录是独立产品展示。根目录 `/` 是实际使用的操作台。展示页不导入机器人通信模块，不向机器人发指令。

## 答辩最快路径

1. 直接打开 `assets/film/CareRover-film.mp4`：150 秒、1080p、30 fps，含原创轻配乐，可离线播放。无需浏览器、网络或烧录。
2. 在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`（Windows 用 `py`），打开 `http://127.0.0.1:8765/presentation/`。
3. 选择「逐页讲解」用左右键/上一章/下一章；「自由探索」用于结构解释。完整进入，停留展开，点选平滑聚焦，拖动和缩放可打断自动镜头，关闭返回原时间并暂停。
4. 「操作台」打开同仓库根页；本地默认模拟。真机必须连接组员验证过的机器人 AP 并打开主控提供的 HTTP 地址。公网 HTTPS 产品页不能充当机器人局域网代理。

「随心浏览」「逐页讲解」「播放影片」使用 `story/director.js` 同一条 150 秒时间轴。Web 影片是实时 WebGL；离线 MP4 是从相同 evaluator 导出的固定帧。手动浏览不会偷偷触发机器人。

## 展示与真实功能

人物为 CC0 衍生角色，身高 1.70 m；桌高 0.740 m；机器人采用原 CAD 米制尺寸，约 0.1295 m。宏观到桌面通过摄影机运动完成，不缩放机器人。影片中的手势、运动、回声、心率/血氧和控制台会话均为明确标识的模拟。健康的 72 BPM / 98% 随接触事件出现，松手清空；不代表医疗验证。

影片含：正面 → 开壳 → 感知 → 桌面尺度 → 前后左右/360° → TWO/DISLIKE/LIKE → 跟随/丢失停止 → 杯子障碍/回波 → 手指/OLED → 生产操作台模拟录屏 → 正面结束。杯子是局部前向测距演示，不暗示全向导航或桌沿检测。

Inspect 使用独立功能组布局，选中时隔离该实例。默认展开总览及选中构图均验证；不承诺任意角度没有二维遮挡。原 CAD 文件不修改，展示外观与线束是衍生层。

## 离线与降级

所有运行资产本地托管，不依赖 CDN。3D 页需要 HTTP；直接双击 HTML 的 `file://` 不支持模块/模型获取。显式 `?static=1`、WebGL 失败或上下文丢失会提供海报及离线影片入口。优先提前把 MP4 复制到放映电脑，并实际试播。

原 V4 七章海报和证据保留为历史，不用它们认定 V6 影片已验收。V6 软件/视觉与真机验收入口：`../docs/V6_ACCEPTANCE.md`。

## 可复现制作

- 人物：`../tools/art/README.md`。
- 150 秒分镜：`story/director.js`；单元测试 `../tests/director.test.js`。
- 录制控制台：使用 `../tools/record_console.mjs` 的 Playwright CLI 模拟操作；录屏不连接硬件。
- 原创环境配乐：`../tools/film_score.py`（NumPy）。
- 导出：`../tools/render_film.py`（Playwright CLI + imageio-ffmpeg），4,500 帧确定时间采样；中间帧位于忽略的 `build/film-frames/`。
- 完整媒体哈希：`assets/film/FILM_MANIFEST.json`；字幕、海报同目录。

静态浏览器/真机运行无需安装这些制作依赖。测试所用 Chromium 桌面和手机尺寸不等于实际 iPhone/Safari 验收。
