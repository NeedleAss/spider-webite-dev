# CareRover V7 产品展示

根目录 `/` 是真实操作台，`/presentation/` 是独立产品展示。展示代码不导入机器人通信模块、不发送实体指令。

## 答辩路径

1. 打开 `assets/film-v7/CareRover-film.mp4`：112 秒，1920×1080，30fps，原创轻配乐；可直接复制到放映电脑离线播放。附 SRT/VTT 与分镜清单。
2. 在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`（Windows 用 `py`），进入 `http://127.0.0.1:8765/presentation/`。
3. 「逐页讲解」支持上下/左右键、PageUp/PageDown、上一章/下一章；空格播放暂停。「随心浏览」与「播放影片」使用同一个 112 秒导演。
4. 「自由探索」完整进入，鼠标停留展开；触屏使用展开按钮。拆合使用已经由用户接受的 V7 样片路径，与剧情逐实例一致。选中固定展开，可拖动打断聚焦、完整旋转/缩放；默认保留安装参照，主动“单独看”才隔离。退出恢复原时间并暂停。
5. 「操作台」进入同仓库根页，本地默认模拟。实物演示连接组员已验收的机器人 AP，使用主控 HTTP 页面。GitHub PR 不是部署站点，也不是机器人局域网代理。

原三段研究保留在 `v7.html`；新手部独立审核在 `hand.html`，含 5 秒接触样片与中性光三视图。新手部与成片仍等待用户视觉审核。

## 内容与边界

机器人主体、分层开壳、表面扫描、超声命中/回波、正交轮系前后左右/360°、直接手势反馈、跟随/等待、接触/动态 OLED、真实生产操作台模拟录屏。默认不再加载完整成人或房间；历史 V6 资产保留，不用于新默认影片或降级。

原始 CAD 米制、保存实例与四轮/四舵机关系保留；展示退出路径不等于实物维修拆卸顺序。新手模是 CC0 衍生完整右手/前臂，Blender 4.5.7 离线摆姿、烘焙并重新导入 GLB；网页不做实时手指或手腕求解。72 BPM / 98% 是模拟，接触前与离开后清空。

所有运行依赖本地托管，无 CDN。网页需 HTTP，`file://` 不支持；`?static=1`、WebGL 失败或上下文丢失提供新海报与 V7 MP4。现场应提前在放映电脑试播 MP4。

软件结果与视觉审核：`../docs/V7_ACCEPTANCE.md`。固件/操作台继续使用 V6，现场烧录/验收依据 `../docs/V6_WINDOWS_AI_PROMPT.md` 与 `../docs/V6_FIELD_RUNBOOK.md`，G01 仍待实测。
