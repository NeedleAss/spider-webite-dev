# 手模制作单：只做正确的一只手，不再建整个真人场景

## 本次工具与交付

本次采用 **Blender + 许可允许使用的完整带绑定手/前臂资产 + 离线检查与动作烘焙**。不要求用户重新扫描整个人，不要求升级整站引擎。工具版本使用制作人员已经稳定掌握的版本并记录。

交付 `hand_source.blend`（含网格、骨架、材质和动作），`hand_demo.glb`（米制），来源与许可文本，三个中性光静帧，以及接触与手势短片。仅有 OBJ/STL 或一张高分辨率照片不是完整动画资产。付费资产能够用于渲染不必然允许公开重新分发可下载网格，需逐项核对授权；不上传未知权限模型到公开仓库。

## 先验模型，再验动作

先检查五指、拇指根部、指蹼、掌指过渡、指甲朝向和腕部连续性。手掌/手背/侧面在中性材质下都必须正常；不能用深黑照明掩盖变形。前臂截断处不要放在镜头中央，保持在画幅外或以袖口自然遮挡。

绑定检查包括左右手对应、每根骨骼的局部轴、骨长、关节活动范围、皮肤权重与扭转变形。不能因为某条骨架以局部 +Y 指向末端，就假定所有现成资产都相同。应以骨架自身坐标和人工检查为准；镜像处理不得留下未处理的负缩放或左右手手性错误。

## 最短的接触动作

静止手型先摆正确；手和前臂整体靠近传感器，指腹朝接触面；接近时减速，稳定贴合，保持，再沿原方向离开。只对必要关节做小幅动画，避免为一个接触特写引入全身实时 IK。

使用传感器表面 contact anchor，而不是 PCB 的包围盒中心。局部与世界空间转换仅在明确层级进行。指腹到表面的法向距离在整个保持段应稳定，不能用强行移动手腕来补偿错误指轴，也不能让指甲接触传感器。

手势准备 open/relaxed、LIKE、DISLIKE、TWO 和需要的 THREE/OK 独立 pose。拇指与其他四指不共用同一弯曲公式。转到 DISLIKE 时由前臂/腕部合理配合，不做没有姿势约束的瞬间180°翻腕。先检查相邻姿势之间的过程，再烘焙动作曲线。

## 烘焙和网页播放

先将 IK/约束结果烘焙到最终变形骨骼。以交付帧率逐帧检查；随机 seek、倒放和停留也不得跳姿。导出后重新导入 GLB 检查骨架、蒙皮、材质、单位和动作片段，不能只看 Blender 内部正确就认为网页正确。

网页只采样已通过的动作，不再用通用角度重建手指。影片、网页和 OLED 使用同一语义时间。接触前显示待机；保持段显示采集中；仅在模拟结果事件后显示同一组示例 HR/SpO2；离开后清空。模拟标签不移到观众无法看到的隐藏面。

## 六项硬门槛

1. 五指、手掌、前臂整体一眼可认，没有单独漂浮的断指。
2. 指甲始终在手背侧，指腹朝传感器；左右手与动作一致。
3. 手腕、拇指根部、掌指关节无折断或反向弯折；没有突然翻面。
4. 无穿模、接触抖动、腕部滑移；起止与反向播放都稳定。
5. 皮肤或哑光材质只是外观选择，不掩盖拓扑/绑定问题。
6. 接触、采集、OLED读数与离开是同一事件，不是三个独立循环。

任何一项失败，手模镜头不得加入答辩成片。健康功能仍可在操作台/实物中解释，不用异常手模型替代。

## 关于真正写实的整个人

完整写实人物是资产、皮肤/眼睛/头发、绑定、动作、接触与灯光的共同结果。MetaHuman/Unreal 是可用的专门制作路线，官方提供带绑定的人物与动画工作流；它不是“换一个GLB就保证没有恐怖谷”。这次明确不把完整人物重新列为交付前置条件。以后做完整人形，应独立拍摄5–10秒样片通过后再接入项目。
