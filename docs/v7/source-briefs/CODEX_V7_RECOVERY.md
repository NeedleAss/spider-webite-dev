# V7 定向收尾指令：回退视觉方向，不回退产品代码

日期：2026-09-18。项目：NeedleAss/spider-webite-dev，PR #1。

## 唯一决定

以当前 `codex/final-polish@f6d7969b1e555313802a2476640f762a86d986cc` 为修改起点，视觉参考回到用户认可的 `7e3a091125028a68a292df645dfe2512e489d4c9`（V4 深色产品叙事）。**不是将整个仓库 checkout/reset 到旧提交，也不是恢复 V4 未解决的开壳和手指缺陷。** 保留新版时间导演、Deck/Scroll/Film、运动/手势章节、动态 OLED、控制台与安全修复，重新编排为机器人主体的摄影棚式展示。

移除默认影片中的完整成人、房间、桌面、椅子及相应人体求解。不要继续调现有人物的皮肤颜色来交差。完整人形留在归档中，不进入新版本的默认加载路径。健康与手势允许同一只完整的、解剖形态正确的中性手模，但必须先通过独立样片验收；没通过不得用现有异常手部替补。

本指令覆盖历史 V5/V6 中“必须真人/房间/桌面”的冲突制作要求，并废弃当前按类型分列的展开实现。最新 V6 的直接手势、手动优先、被动页面不抢权、中立再准入、视频时效与控制保护，不受视觉回退影响。用户这次没有授权回滚设备固件或自动合并 PR。

## 先保存现场，而不是先动手覆盖

执行并保存 `git status --short`、分支、HEAD、未提交 diff。保留组员改动，建立工作分支。历史 V4 放在单独 worktree 或只读目录对照，禁止 `git reset --hard 7e3a091` 和无差别 `git restore --source=... .`。

记录本轮开始时 firmware/、js/、css/、根 index.html、设备配置和现有控制测试的哈希。视觉任务默认只修改 presentation/、专门的展示/导出测试和相关文档。共享导出工具确需更改时单独解释。完整测试仍需运行，不用“这些文件没改”冒充测试已执行。

## 先交样片，禁止直接重做整支影片

先只交以下三段，附固定镜头、正反向录像及版本：

1. **结构段**：完整 → 有序紧凑展开 → 停留 → 收拢。镜头先固定，无遮挡功能组、无非设计穿透、不是平面展板。
2. **视觉段**：镜头端面 → 有表面承接的薄扫描光效 → 目标框 → 停止/消失。不是几根漂浮线条。
3. **回波段**：端面出波 → 接触实体障碍表面 → 从命中处形成返回波 → 回到模块。不是同一圆环折返。

每段约 6–10 秒只是试片长度，不是机械真实时间。结构段通过前不继续房间、人物或长片生产。手模另交中性光下的正面/侧面/背面静帧与约 5 秒接触样片；静帧或动作不合格就停止该分支，不能用代码测试替代视觉验收。

## 必修 A：重写 inspection.js 的布局原则

当前 `presentation/scene/inspection.js:3–9` 把 15 类中心中的 14 类设为 x=0，目标中心范围只有 20 mm 深、610 mm 高、490 mm 宽。轮与舵机还按类型和数组序号分列。这不是机械爆炸图。删除这种“按类型重新排到格子”的终态生成逻辑。

目标是**以底盘为锚、保留前后左右关系的分级爆炸图**：

- 顶盖 + OLED 作为一组沿原上方抬起。总览不把屏幕与盖分到两列；讲 OLED 才进行组内第二级分离。
- 外壳先沿实际可退出方向让出包络，再以有限偏移让出主视线。不得凭镜头正面看不到穿透就判定合格。
- 主控 + 支架/外框按真实安装关系成组，先与外壳分开，再在选中时展开组内；不将所有支架从原方位调换。
- 相机与安装架、超声与其固定基准，沿各自装配方向有限分离。局部 +Z 向前和原 CAD 世界轴保持一致。
- 每一角轮—舵机保留对应关系，轮沿自身轴退出；不能把四轮排成一组、四舵机排成另一组来获得“无遮挡”。
- 电源和底盘维持原上下关系，不为排版互换上下。紧固件跟随所属子装配，不抢占主画面。
- 未知的退出顺序/轴从用户将提供的安装图和 CAD 核对；先列待确认项，不编造刚性拆装路径。

总览与选中共用一套 assembly tree 和路径，仅开放层级/幅度不同。不存在另一个与原装配无关的平面目录模式。每实例保存不可变 rest TRS；姿态从 progress 直接计算。屏幕/盖同组阶段的相对矩阵保持不变；轮—舵机对应关系不可由数组顺序推导。

三类问题分别验收：真实网格穿透、相机投影遮挡、主次与间距。AABB 相交只用于筛查，薄壳包围盒包含内部本来就是正常的；不能据此自动判穿透。默认总览重点件必须可辨、选中件关键面无遮挡；不承诺任何观察角度都零投影重叠。

路径必须在 0/25/50/75/100% 及正反向连续播放中检查。检查正面、前侧、侧面、顶视，而不只检查最后一张截图。相机取景适配完整外观和说明面板；不要用全局放大/缩小来掩盖布局错误。

## 必修 B：剧情开壳和自由探索一起修

`presentation/story/timeline.js:43–53` 的旧 partOffset 仍被 robot.apply 使用；它只给顶盖、屏幕、外壳、主板外框默认位移。不能只修 inspection.js 就宣称故事中的重叠也解决。将两处统一到上面的装配路径数据。

自由探索必须完整进入。细鼠标意图停留后展开，选中后固定；移到说明区不收拢。触屏显式展开。保留水平 360°、上下方、放大缩小和稳定退出；聚焦可被拖动打断。默认保留必要安装参照，只有主动“单独看”才彻底隔离所选部件。退出回先前影片/章节并暂停，不自动恢复实体动作。

## 必修 C：摄像头光效不是修改颜色

保留正确端面锚点与父级变换；不要恢复世界坐标固定 +Z 的旧错误。摄像头并非主动激光仪，绿/青光是感知示意，短标识明确，不改变产品硬件说明。

参考 Dyson 的“受照表面能看见细节”的视觉目标，制作薄光片/受控视域，必须有明确目标表面承接。主要亮度落在命中区域，空中体积光很轻，边缘软化、距离衰减、有遮挡。目标可为检测画面内的抽象人脸轮廓，不放微型成人在机器人旁。没有真人不等于删掉手势和跟随内容。

技术方向：统一 sensor frame；目标材质中的局部扫描条带或投影遮罩负责表面响应；低密度体积片只辅助。depthTest=true，透明效果按需求 depthWrite=false，明亮不等于全屏 bloom。四角框跟随检测平面/目标投影，识别后扫描消退、框保留片刻。扫描面不得穿出视域、透过机身或盖住镜头。

固定时间可重访；同一进度反向浏览得到同一效果。先交镜头近景样片，不接受“shader 已编译”作为效果验收。

## 必修 D：超声要有命中与回波的因果

撤换只靠 RingGeometry + 周期三角波平移的表现。沿模块端面法向发出少量弧形/扇形波前；前方仅需一块有真实表面的简洁障碍，不再建房间/桌子。命中点来自该表面的几何或经过核验的指定点。

出射波到达命中点以后才产生回波，返回波从命中位置回到接收区域；强度、宽度与时间有区别。不是把同一个环以原大小倒着拉回来，也不是直接画到障碍后面。停止/绕行与回波判断由同一演示事件驱动。声波可视化与放慢均为原理示意；TX/RX、真实声束和测距数值未核对不填成实测。

## 必修 E：手部改用已审查的烘焙动作

执行 `HAND_ASSET_BRIEF.md`。废弃当前默认发布路径对 adult.glb + actor.js 的运行时肢体求解依赖。不能只把 adult.visible=false；app.js 的静态 import、Promise.all、poseScene 及旧 fallback/海报/MP4 都必须清理，确保新展示不会仍加载或回退到不满意的影片。

手模使用完整手掌、五指与一段前臂，末端在画幅之外或用自然袖口处理。可用中性哑光材质，不必仿真皮肤。模型正确不代表动作正确：在 Blender 中检验左右手、骨轴、权重、手腕/手指关节和接触方向，将动作烘焙成片段后再交网页播放。禁止给所有手指统一套一个局部 X 角度，禁止运行时翻转手腕来临时拼手势。

接触位置使用指腹、健康模块表面法向和不穿模约束；保持接触时不漂移。OLED 与手部来自同一个 event。读数持续标识为模拟；接触前不出值，离开后清空。健康模块的光学解释以本机 MAX30102 为准，不因参考 Apple 而更改器件原理。

## 保留内容与成片收尾

保留“怎么转，都有范”：前/后/左/右/原地360°/停稳；不以摄影机绕行代替机器人动作。保持正交轮系，不回退成四轮同向假转。手势识别可在镜头图像平面中用清楚的符号和经审查的手模呈现；所需动作遵守当前固件映射，不重演已过期的网页授权流程。

保留动态 OLED、真实生产操作台的演示入口、Scroll/Deck/Film 同一时间轴、离线 MP4 和字幕。删除照片末页、房间和真人情节。成片时长服从已通过的镜头，不为了填满150秒保留差镜头。初步可收为约100–120秒，但先样片后定长，禁止宣称已做完新成片。

## 最终放行

软件回归、视觉可看、实体动作是三张验收表。原始截图/录像、内容版本、模型/字幕/影片哈希必须与候选一致。至少一名非制作同学观看样片，确认“结构仍看得出原装配”“扫描和回波有明确方向与结果”“手没有翻转/断裂”。用户未接受试片前，不批量渲染长片。

保留当前控制台、视频时效和固件测试结果并重跑相关检查；G01 等现场待验项仍按真实测量关闭。UI/视频的通过不授权硬件动作，不把未执行填成 PASS。
