# V7 第一轮视觉样片

基线 `f6d7969`，工作分支 `codex/v7-samples`。本次只交结构、扫描、回波三条视觉样片供用户审核，尚未制作新长片或手模，未替换 V6 默认入口。

## 直接观看

仓库根目录启动 HTTP 服务后，打开 `http://127.0.0.1:8765/presentation/v7.html`。页面提供三段切换、播放、暂停、倒放、进度拖动、轨道旋转与缩放；结构另有前侧、正面、侧面、顶视。无需连接机器人。

三个离线 MP4 位于 `presentation/v7-media/`：

- `structure.mp4`：10 秒固定镜头，完整 → 顶盖/OLED → 外壳 → 功能组 → 收拢。
- `scan.mp4`：10 秒镜头与检测表面特写，薄光片落到目标表面，随后保留检测框，再消退。
- `echo.mp4`：10 秒发出、障碍命中、独立返回和接收判断；出射与回波具有不同波前、起点和强度。

均为 1920 × 1080、30 fps、300 帧无声样片。网页与影片采样同一进度逻辑；文件及制作源码哈希见 `presentation/v7-media/MANIFEST.json`。手机布局仅在桌面 Chromium 的 390 × 844 尺寸检查，非真实手机验收。

## 本轮制作决定

摄影棚式深色背景，白色打印壳体保留真实轮廓；使用大面光源反射塑造金属、镜头和外壳。样片不加载成人模型、房间或旧影片。未使用照片末页或完整人形。

结构保持原始 CAD 静止变换：顶盖与 OLED、相机与安装架、主控与支架/外框成组。四轮与舵机采用固定实例 ID 配对，轮沿各自轴退出。外壳上移前先给镜头/超声端面留出收回量，再进行有限侧移；这是**展示退出路径**，实物紧固件、安装顺序和真实可拆方向仍需安装图/原生装配验证，不作为维修拆装教程。

扫描采用自主绘制的抽象面部轮廓与标记点作为检测图像，亮带作用于同一目标材质，空气薄片只作辅助。摄像头没有可见激光发射，画面持续标注感知可视化。

回波命中点由实际障碍网格求交获得，返回波从命中处产生。波前带有障碍平面裁切，避免穿到障碍后方；它是放慢的模块级原理示意，不指定未核验的 TX/RX 身份，也不输出伪装成实测的距离数值。

## 验证及审核边界

`evidence/v7-samples/` 保存本轮证据：

- 35 项浏览器检查：子装配关系、正反向姿态一致、收拢复位、播放/暂停/倒放、扫描和回波时序、反向 seek 后截图一致、手机尺寸及浏览器/着色器错误检查。
- 20 张结构路径截图：0/25/50/75/100%，四个角度。另有编码后影片的抽帧联系表。
- 三支影片完整解码通过，并在 Chromium 以 2 倍速完整播放到结尾。
- 51 Node、38 Python、12 套 C++ 回归重新执行并通过；V6 资产清单检查通过。75 个固件、控制台和配置文件哈希保持一致。

这些检查不等于视觉已被用户接受，也不构成全网格连续碰撞、原生 CAD 或实物验收。顶视等角度出现投影遮挡是单独观察项；包围盒不相交没有被用作机械正确性的通行证。全部硬件项目与 G01 保持原有现场待验状态。
