运动章各采样约 3 秒：桌面与 390 宽模拟视口约 120 FPS，p95 帧间隔约 9–10 ms；这是本 Mac 的结果，不是手机性能承诺。整机约 36,046 三角形、133 draw calls；低于三角形预算，但 **超过 <100 calls 的初始软目标**。本轮保留实例独立选择和材质，接受该软预算偏差，真实低端手机需现场检查，必要时用静态模式。预热全章后资源保持约 153 geometries / 15 textures，反复遍历无增长。

源码、依赖、海报总量与实际请求字节数记录在机器可读结果。全部请求在本地 origin；没有 CDN、机器人 WS 或外部运行时请求。这里验证的是本地依赖完整性；未冒称实测关闭 Mac Wi-Fi 或每种物理浏览器。

编译第一次已完成 C++，但系统 Python 缺少 `construct`，FFat 阶段失败；改用项目已有 `.venv` 重跑成功。沿用上一轮项目内 native ctags 覆盖，不替换系统工具。构建是占位配置 compile_only，不能交给组员直接烧录。

## 真实外观的明确取舍

| 项目 | 已完成 | 尚不能当作事实的部分 |
|---|---|---|
| 结构与安装 | 原始结构网格、保存实例矩阵、隐藏第四舵机矩阵 | 原生 CAD 配合/连续拆装碰撞计算、实际是否装齐、最终安装深度 |
| 关键硬件外观 | 器件特征与大件、排针、接口、网面、标签、轮滚子 | 载板小元件与隐藏面为简化；没有扫描、没有新的完整写实 GLB |
| 端面间隙 | 摄像头外观局部 Z +0.5 mm、OLED 外观局部 Y +2.5 mm 消除共面/埋入 | 是显示处理，非测量/重新安装；原安装矩阵保留 |
| 线束 | 六类模块关系、有限长度彩色曲线；过大拆解省略连接 | 未逐针电气布线、未机械线缆碰撞求解；不是最终实物走线 |
| 轮系 | 两组正交主动轴，几何符号独立于电气反转，转向阶段不平移 | 滚子为切向轴对称表面，未逐个实现接触动力学；不是轮速/接地标定 |
| 传感器情节 | 局部朝前视域、出波/回波、先转向再跟随、失去目标停止 | FOV/声束/TX-RX/人物轨迹是示意，无实测值 |
| 健康/OLED | 接触原理与 DEMO 蓝色屏 | 不生成诊断、心率/血氧/电量结果 |
| 来源 | 团队照片、自制几何/纹理、MIT Three.js | 不发布商家贴图、个人卡片、原 PDF 或原始 CAD |

## 复现与回退

```sh
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/check_firmware.py
python3 tools/appearance_manifest.py --check
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器终端另开，安装环境按项目/Playwright CLI 说明准备，使用 `npx --yes --package @playwright/cli@0.1.20 playwright-cli open http://127.0.0.1:8765/presentation/ --headed`，再把 `tests/browser/check_story.js`、`check_story_resilience.js` 的完整 async 函数字符串作为 `run-code` 参数。控制台检查单独浏览器 session 执行 `check_display_semantics.js`，避免测试 fixture 污染展示页。`capture_story.js` 会更新海报；更新后需重新生成资产清单。完整执行器见 `tools/run_visual_checks.py`。

展示故障优先加 `?static=1`，也可播放交付录像。原始基线保留于 Git `72ee475...`，需旧展示时在独立目录检出它；不覆盖当前工作区、固件或私有配置。原始照片/CAD、旧 ZIP/历史报告没有被覆盖。
