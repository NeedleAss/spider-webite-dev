## 0. 第一优先级：今晚的真实操作不能让位于电影美术

主控安全任务自身停摆后的独立 PWM 撤销（G01）仍为实体动作发布阻断。软件测试/影片/UI通过不关闭它。不要把同一个 safetyTask 内240ms期限当独立保证；未满足实物门槛，明天只做observe/识别/健康反馈和明确模拟或录像，不标现场动力已通过。

保留 +X IMU 安装、NVS门禁、已批准阈值、命令/来源期限、停止取消、回放禁发命令和原功能边界。不要为了更顺滑删断连/人物丢失/倾倒停车。

## 1. 必须先核验并处理的三个代码问题

### C01 网页手势模式与动作所有权冲突

生产 `setMode(client,GESTURE_CONTROL)` 设 owner=client，`wirelessGesture()` 调 `autonomousTurn/autonomousFollow` 却要求 owner=0。本包GT09/10在SAFE/DEMO都复现CONTROL_BUSY；IDLE也不释放owner。

不要删busy检查。选择一种明确的受监督手势语义：已有网页gesture模式代表什么、谁保持授权、LIKE进入follow怎样继承监督、谁能停止、断连/心跳断开怎么撤销。在控制器/runtime/UI/测试同时闭合。当前网页心跳加速主要针对FOLLOW，不能假定GESTURE已有同样监督。

若冻结前不能完成并验证，把该路径从现场动作演示撤下，界面明确“识别监视/动作未启用”。不要把“断开网页让owner=0”做成默认接管技巧。当前control_allowed=true不证明self-owner，不填不存在的owner/session字段。

### C02 视频ready不是新帧

`VideoPanel.render()` 用naturalWidth>0恢复ready；没有新帧时效。先分清WS、robot数据、JPEG到达、人物/手势数据，不能一灯代表全在线。显式视频错误/切源由应用协调层撤销本操作者输入；重连后重新按住，不继承旧速度。

逐帧时效需要真正解码/到达事件。IMG load/naturalWidth、图像像素变化、CAM编码计数都不能替代浏览器实际收到新帧。requestVideoFrameCallback不能用于IMG。可以在现有直连CAM/CORS边界内做有界multipart接收解码；必须限制内存、旧请求代次、重试和恢复，验Safari/目标浏览器。来不及则诚实显示“帧时效未核验”，只做已验证、现场直视操作，不能盲操。

不要今晚换WebRTC、建立云视频或把视频转发压到主控HTTP/控制任务。已有单viewer限制保留并告知，第二终端不自动抢流。

### C03 急停设备报告要用robotFresh

V5已复现health-only遥测使旧robot ESTOP看似新确认。使用lastRobotTs及合法时基判定，保留本地急停锁，不因状态过期解除控制。加robot静默/health正常、imu正常、PPG正常三类回归。

## 2. 操作台：从样稿移植层级，不替换控制逻辑

入口仍是根目录index.html；presentation独立。展示导航新增“操作台”，显式区分浏览器模拟与设备同源控制，导航不发送模式或动作。

参考 `design/console-reference.html` 的分组：稳定顶部来源与停止、大4:3视频、右侧模式/目标/控制、视频下的识别与动作状态、健康区、折叠诊断。小屏视频→控制→健康，停止始终可触达。样稿所有数值是模拟，不可原样带入生产真机页。

保留MotionInput/Transport/protocol/state分层；视频模块不能反向import运动Transport。控制台不放电影背景、循环动画或3D场景。圆角、字体、状态面强调可读性，不用过度玻璃影响反馈。常用按钮至少44CSSpx；任何UI缓动不延迟停止。

状态清楚区分：未连接、同步中、当前允许请求/只读、请求中、设备确认、等待目标、转动中、识别保持、拒绝、视频失效、急停本地锁/设备上报、健康无信号/采集中/有效/保持、回放。AI FPS不是视频FPS，target不是实际轮速。

动作事件当前只在串口，WS稳定标签不是动作ACK。可添加有界的只读动作事件遥测并同步协议测试；没有事件就写未确认，不猜拒绝原因或执行成功。

## 3. 发布片：150秒，必须补独立运动和手势

按 `config/FILM_TIMELINE_V6.json` 落地。时长可小幅调整但每段必须有动作、结果和停留点。

- 40–60秒独立运动：前进4秒、后退4秒、右移3秒、左移3秒、原地360°5秒、停留1秒。“怎么转，都有范。” 方向以机身为准，摄影机不能把前后左右混淆。
- 60–82秒手势：TWO顺时针/THREE或OK逆时针、DISLIKE普通停止、LIKE进入跟随。不是挥手就能任意控制；遵循现有映射，保留确认过程与权限条件。展示识别→准入→动作→OLED/操作台反馈。
- 130–143秒操作台：同屏看到视频/识别/指令/停止状态。可使用清楚标记的Mock录像，不能冒充实物验证。

其余保留开壳、真实比例拉远落桌、跟随失去目标停止、杯壁去回声波、真实可辨的手接触到顶部OLED模拟值。末页完整机身定格，删除照片入口及其事件引用，交给现场拿实物。

原CAD/rest矩阵不变；人物/桌子/杯子用米，机器人不随镜头乱缩放。真实镜头能看见脸/手才画框，手要满足视觉叙事中的足够大小；不改固件阈值迁就远处小手。

模拟健康值可以72BPM/98%SpO2，必须标“模拟读数/过程压缩”，接触事件与OLED同源，松手清空。真实OLED已有手势和健康数据入口，不能把虚拟文案当作固件已经支持的屏幕内容。

完整转圈使用unwrapped yaw，不用0与360相同四元数最短插值。真实两组正交轮对要按实例轴映射，前后左右与轮子一致，舵机壳不随轮旋转。

## 4. 一套时间与资产，四种使用方式

Film自动视频、Deck逐页、Scroll滚动共用事件/时刻。Inspect是独立交互状态，进入时暂停时间和声音，退出恢复原语义位置且不自动续播/运动。

Inspect默认完整，鼠标意图停留后展开；选中后固定；触摸有显式展开按钮；360°含上下方，滚轮/双指缩放。StoryOpen、InspectExploded、PartFocus三个布局，不把所有offset乘二糊弄。主控/支架/外框/电源/各模块都要有合理空间位置。每个零件镜头按自己的表面/功能基准，过渡可被用户打断；只运行当前选中件效果。

不要承诺360°所有观察角度无投影遮挡；验收独立件无非设计穿透、默认总览可区分、聚焦重点可见。过渡也采样，不只看终态。大拆解中线束有限长度，不无限拉伸、不猜GPIO。
