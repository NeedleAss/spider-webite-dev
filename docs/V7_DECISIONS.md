## 2026-09-18 三维交互场景更新

根据用户最新反馈，生产特写从完整整机推进，经连续透明度过渡显露传感器，保持原装配位置与半透明机身参照，结束再回到整体。扫描目标替换为素色、无表情、无皮肤纹理的立体人头；超声目标为具有杯口、内壁、底部和把手的陶瓷杯，中心声线与杯身实际网格求交。此为概念功能特写，不是整个人体与实物场景的等比例复刻。

TWO / DISLIKE / LIKE 使用离线摆姿并烘焙的完整右手网格，沿用健康手模的同源 MakeHuman CC0 拓扑。DISLIKE 使用 LIKE 的整体旋转，网页不实时扭曲手指。旧平面手势卡片在生产故事中隐藏，确认、执行和 OLED 语义保留。原结构/扫描/回波研究 `v7.html` 作为历史参考保留其原目标；用户最新要求落实在正式产品页、自由探索传感器效果及重新导出的长片。

新资产及许可在 `presentation/assets/interaction/`；可复现构建脚本 `tools/art/build_interaction.py`，需既有 pinned MakeHuman 源和 Blender。新特写与手势仍等待用户视觉审核。此次不修改固件、真实操作台或心率接触手模。

## 2026-09-19 识别与跟随合并

按用户要求，原 18–28 秒摄像头特写与后置 70–80 秒跟随章节合并为 18–38 秒连续镜头。先特写扫描人头，26–28 秒恢复完整整机并拉远；同一个人头保持在场景内，28–38 秒左右移动、持续扫描确认，机身延迟 0.65 秒沿对应横向轨迹响应，最后停稳。跟随过程固定相机，人头世界坐标独立于机身，不能随挂载传感器一起被带走。
