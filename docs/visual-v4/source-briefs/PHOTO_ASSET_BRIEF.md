# 实物资料收集单｜把现有 CAD 变成“我们的机器人”

目标不是从零重做机械设计。CAD 保留每个模块的位置、实例与关系；照片和尺寸补充外形、真实表面和线束。当前展示资产没有贴图/UV，且包含建模代理，所以只换颜色不能得到真实复刻。

## 最先提供的材料

| 类别 | 拍什么 / 写什么 | 用途 |
|---|---|---|
| 正面定义 | 一张正对摄像头和超声波的完整整机照，再一张轻微斜侧照 | 固定首页、收拢、静态海报和所有坐标 |
| 外壳 | 前、后、左右、顶部；保留真实孔位和打印表面 | 外形/开孔/比例/材质核对 |
| 轮组 | 一个轮子的正面、侧面，轮径；型号或购买名称 | 确认真正轮型、滚子和轮毂，不用圆柱冒充 |
| 舵机 | 型号、外壳/轴/安装耳/线出口；说明四个是否均在车上 | 外观替换；核对源装配隐藏的第四实例 |
| 主板 | 清楚的正面、可安全拍摄时的背面；板长宽、型号 | 芯片/排针/接口/丝印和安装方向 |
| 相机与超声 | 清晰近景、侧面突出量、模块型号 | 镜头/端面锚点、正确前方、TX/RX标记确认 |
| 假线代理 | 指出两条矩形块在真实机器里对应哪组线，拍两端连接器与中间走线 | 分离代理块，制作有正确端点的柔性线束 |
| 内部整体 | 已安全断电、在本来可开启状态下的一两张内部全景 | 判断是否有明显装配或外观差异 |

给每个文件一个明确名字，例如 `robot_front.jpg`、`camera_side.jpg`、`controller_top.jpg`、`controller_cable_route.jpg`。型号不明可以写“未确认”，不要补一个看起来相似的型号。

照片不必先达到摄影棚水平。优先清晰、真实、同一版本：均匀柔光、稳定焦点、避免人像虚化、避免强滤镜；在至少一张参考图旁放尺子。尽量固定曝光和白平衡，让白壳和黑轮子都有细节。

## 必须确认的差异

- 保存装配有20个可见实例、4个轮子、3个可见舵机，另一个舵机被隐藏。实际成品是什么状态？
- 相机/超声的传感器面确实是首页正面；侧面屏幕的位置是否与最终外壳一致？
- 主板下的两个矩形代理是否完全对应线束，是否还混有真实支架/插座？
- 线束是否在真实完整机身中外露？应该显示到什么程度？

只改衍生展示模型并记录差异，不覆盖原 CAD，也不因外观修改而改变接线或固件参数。

## 全车扫描不是必选项

有时间再考虑均匀重叠的多角度照片或 Object Capture；它更适合外观参考，不能自动给出隐藏零件、真实接线关系与独立可拆解的装配树。白色无纹理外壳、镜头玻璃、反光金属和细线可能需要额外清理。依据：Apple 官方 Object Capture 介绍及主报告 W06。

本次优先级：**正面整机 → 镜头/超声 → 轮组/舵机 → 主板/假线 → 其他细节**。缺少部件背面时可以保留简化，但不要声称完整扫描复刻。

## 拍摄安全与资料隐私

不为拍照让轮子转动，不翻转带电运行的机器人，不拆不明接线。由现场人员先断开动力并确认安全；原有可开启外壳之外的拆卸不是本收集单的要求。

原始照片保留私有副本；展示副本检查人脸、Wi-Fi口令、序列号和个人信息。使用厂商模型/环境贴图时保留许可，不上传原CAD到未知在线转换站。不给照片打“美化”滤镜来掩盖实际结构差异。
